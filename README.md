## Overview

Dexed is a cycle-accurate emulation of the Yamaha DX7 FM synthesizer, reading original DX7 SysEx patches and reproducing the six-operator FM engine, envelopes, and LFO of the original hardware.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Dexed** delivers the features you need in a clean, intuitive package.

</div>

## Key Features

| Feature | Description |
|---------|-------------|
| **DX7 Emulation** | Cycle-accurate six-operator FM synthesis matching hardware output |
| **SysEx Import** | Load original DX7 and DX11 patch SysEx banks directly |
| **Patch Browser** | Built-in browser for navigating thousands of DX7 preset banks |
| **Operator View** | Individual operator level, ratio, and envelope control per operator |
